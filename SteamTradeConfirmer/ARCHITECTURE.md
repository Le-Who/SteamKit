# Архитектура Steam Trade Confirmer

## Обзор

Steam Trade Confirmer построен по принципам MVVM (Model-View-ViewModel) с использованием WPF и SteamKit2.

## Структура проекта

```
SteamTradeConfirmer/
├── Models/                    # Модели данных
│   ├── SteamAccount.cs       # Модель аккаунта Steam
│   └── TradeOffer.cs         # Модель обмена
├── Services/                  # Бизнес-логика
│   ├── SteamClientService.cs # Управление подключениями к Steam
│   ├── SteamAuthenticator.cs # Аутентификация через .maFile
│   ├── TradeOfferService.cs  # Работа с обменами
│   ├── AccountStorageService.cs # Сохранение аккаунтов
│   └── TOTPGenerator.cs      # Генерация TOTP кодов
├── Views/                     # Пользовательский интерфейс
│   ├── MainWindow.xaml       # Главное окно
│   ├── MainWindow.xaml.cs    # Код-бихайнд главного окна
│   ├── AddAccountDialog.xaml # Диалог добавления аккаунта
│   └── AddAccountDialog.xaml.cs
├── App.xaml                  # Конфигурация приложения
└── App.xaml.cs              # Точка входа
```

## Компоненты

### 1. Models (Модели)

**SteamAccount**
- Хранит данные аккаунта (логин, пароль, путь к .maFile)
- Реализует INotifyPropertyChanged для привязки данных
- Отслеживает статус аутентификации

**TradeOffer**
- Представляет обмен Steam
- Содержит информацию о предметах, получателе, времени создания
- Статус обмена

### 2. Services (Сервисы)

**SteamClientService**
- Управляет подключениями к Steam для каждого аккаунта
- Обрабатывает события аутентификации
- Запускает циклы обработки колбэков

**SteamAuthenticator**
- Реализует IAuthenticator из SteamKit2
- Читает .maFile и генерирует TOTP коды
- Обрабатывает ошибки аутентификации

**TradeOfferService**
- Получает список обменов (заглушка)
- Подтверждает и отменяет обмены (заглушка)
- В будущем будет использовать Steam Web API

**AccountStorageService**
- Шифрует и сохраняет данные аккаунтов
- Использует Windows Data Protection API
- Сохраняет в %APPDATA%/SteamTradeConfirmer/

**TOTPGenerator**
- Генерирует TOTP коды для Steam Guard
- Реализует RFC 6238
- Поддерживает Base32 декодирование

### 3. Views (Представления)

**MainWindow**
- Главный интерфейс приложения
- Список аккаунтов слева
- Таблица обменов справа
- Кнопки управления

**AddAccountDialog**
- Диалог добавления нового аккаунта
- Поля для ввода данных
- Выбор .maFile

## Поток данных

```
1. Пользователь добавляет аккаунт
   ↓
2. AccountStorageService сохраняет данные
   ↓
3. SteamClientService создает подключение
   ↓
4. SteamAuthenticator генерирует TOTP код
   ↓
5. SteamKit2 выполняет аутентификацию
   ↓
6. TradeOfferService получает обмены
   ↓
7. UI отображает список обменов
   ↓
8. Пользователь подтверждает/отменяет обмен
```

## Зависимости

- **SteamKit2**: Основная библиотека для работы с Steam
- **System.Security.Cryptography.ProtectedData**: Шифрование данных
- **System.Text.Json**: Сериализация JSON
- **WPF**: Пользовательский интерфейс

## Безопасность

1. **Шифрование данных**: Используется Windows Data Protection API
2. **Локальное хранение**: Данные не передаются в интернет
3. **TOTP генерация**: Коды генерируются локально
4. **Изоляция аккаунтов**: Каждый аккаунт в отдельном SteamClient

## Ограничения текущей версии

1. **Заглушки для обменов**: Реальные API вызовы не реализованы
2. **Нет API ключа**: Требуется Steam Web API ключ для полной функциональности
3. **Только исходящие обмены**: Входящие обмены не поддерживаются
4. **Нет автоматического обновления**: Только ручное обновление списка
