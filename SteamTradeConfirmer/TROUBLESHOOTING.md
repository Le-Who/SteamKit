# 🔧 Руководство по устранению проблем Steam Trade Confirmer

## 🚨 Проблема: "Таймаут подключения к Steam (10 секунд)"

### 📊 Диагностика по логам

Если в логах вы видите:
```
🛑 Цикл обработки колбэков завершен после 0 итераций. IsConnected: False
🚨 КРИТИЧЕСКАЯ ПРОБЛЕМА: CallbackManager завершился немедленно!
```

**Это означает, что SteamKit2 не может установить соединение с серверами Steam.**

### 🔍 Возможные причины и решения

#### 1. 🌐 Сетевые проблемы
**Симптомы:** Steam Community/API недоступен
**Решение:**
- Проверьте интернет-соединение
- Запустите `network_diagnostics.bat` для диагностики
- Попробуйте отключить VPN/прокси временно

#### 2. 🔥 Блокировка файрволом/антивирусом
**Симптомы:** Приложение не может подключиться к Steam серверам
**Решение:**
- Добавьте SteamTradeConfirmer.exe в исключения антивируса
- Добавьте правило в Windows Firewall для приложения
- Временно отключите антивирус для тестирования

#### 3. 🚫 Блокировка портов Steam
**Симптомы:** Проблемы с портами 27015-27030
**Решение:**
- Проверьте настройки роутера/модема
- Убедитесь, что порты Steam не заблокированы
- Попробуйте другую сеть (мобильный интернет)

#### 4. 🏢 Корпоративная сеть/прокси
**Симптомы:** Работает дома, но не работает в офисе
**Решение:**
- Настройте прокси в Windows
- Обратитесь к IT-администратору
- Используйте VPN

#### 5. 🌍 Географические ограничения
**Симптомы:** Steam заблокирован в вашем регионе
**Решение:**
- Используйте VPN
- Проверьте статус Steam в вашем регионе

### 🛠️ Пошаговая диагностика

1. **Запустите диагностику сети:**
   ```bash
   network_diagnostics.bat
   ```

2. **Проверьте логи приложения:**
   - Откройте папку: `%APPDATA%\SteamTradeConfirmer\Logs\`
   - Найдите файл с сегодняшней датой
   - Ищите сообщения с эмодзи: 🔍, ⚠️, 🚨

3. **Проверьте доступность Steam:**
   - Откройте https://steamcommunity.com в браузере
   - Откройте https://api.steampowered.com в браузере

4. **Проверьте настройки Windows:**
   - Windows Firewall
   - Антивирус
   - Прокси настройки

### 📞 Получение помощи

Если проблема не решается:

1. **Соберите информацию:**
   - Логи из `%APPDATA%\SteamTradeConfirmer\Logs\`
   - Результат `network_diagnostics.bat`
   - Описание вашей сетевой среды

2. **Опишите проблему:**
   - Что именно происходит
   - Когда началась проблема
   - Что вы уже пробовали

### 🔄 Альтернативные решения

Если стандартное подключение не работает:

1. **Используйте мобильный интернет** для тестирования
2. **Попробуйте другую сеть** (другой Wi-Fi, кабель)
3. **Используйте VPN** для обхода блокировок
4. **Обратитесь к провайдеру** интернета

### 📝 Часто задаваемые вопросы

**Q: Почему приложение не подключается к Steam?**
A: Это обычно связано с сетевыми проблемами, блокировкой файрволом или антивирусом.

**Q: Работает ли приложение через VPN?**
A: Да, если VPN не блокирует Steam серверы.

**Q: Нужно ли открывать порты в роутере?**
A: Обычно не нужно, но может потребоваться в корпоративных сетях.

**Q: Безопасно ли добавлять приложение в исключения антивируса?**
A: Да, приложение не содержит вредоносного кода.
