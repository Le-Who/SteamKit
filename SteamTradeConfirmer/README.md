# Steam Trade Confirmer

Десктопное приложение для подтверждения исходящих обменов Steam без использования мобильного телефона.

## Описание

Steam Trade Confirmer — это легковесное WPF приложение, которое позволяет управлять и подтверждать исходящие обмены в Steam для нескольких аккаунтов. Приложение создано на базе библиотеки SteamKit2.

## Основные возможности

- ✅ Добавление нескольких аккаунтов Steam
- ✅ Аутентификация с использованием мобильного аутентификатора (.maFile)
- ✅ Просмотр списка исходящих обменов
- ✅ Подтверждение и отмена обменов
- ✅ Безопасное хранение данных аккаунтов
- ✅ Современный пользовательский интерфейс

## Требования

- Windows 10/11
- .NET 8.0 Runtime
- Файлы мобильного аутентификатора (.maFile) для каждого аккаунта

## Установка

1. Скачайте последнюю версию приложения
2. Распакуйте архив в любую папку
3. Запустите `SteamTradeConfirmer.exe`

## Использование

### Добавление аккаунта

1. Нажмите кнопку "Добавить" в левой панели
2. Введите имя пользователя и пароль Steam
3. Выберите файл .maFile для мобильного аутентификатора
4. Нажмите "Добавить"

### Работа с обменами

1. После успешной аутентификации аккаунт появится в списке
2. Нажмите "Обновить" для получения списка обменов
3. Используйте кнопки "✓" (подтвердить) или "✗" (отменить) для управления обменами

## Безопасность

- Данные аккаунтов шифруются и сохраняются локально
- Пароли и секретные ключи не передаются в интернет
- Все операции выполняются через официальные API Steam

## Получение .maFile

Для работы приложения необходим файл мобильного аутентификатора. Получить его можно с помощью:

- Steam Desktop Authenticator
- SteamAuth
- Других инструментов для извлечения данных аутентификатора

## Ограничения

- Поддерживаются только исходящие обмены
- Требуется наличие .maFile для каждого аккаунта
- Приложение работает только на Windows

## Поддержка

При возникновении проблем:

1. Убедитесь, что .maFile актуален и не поврежден
2. Проверьте подключение к интернету
3. Убедитесь, что аккаунт не заблокирован Steam Guard

### 🔧 Диагностика проблем

Если приложение не подключается к Steam:

1. **Исправьте кодировку консоли (если видите кракозябры):**
   ```bash
   fix_encoding.bat
   ```

2. **Запустите диагностику сети:**
   ```bash
   network_diagnostics.bat
   ```

3. **Проверьте логи приложения:**
   - Нажмите кнопку "Открыть логи" в приложении
   - Ищите сообщения с эмодзи: 🔍, ⚠️, 🚨

4. **Прочитайте руководство по устранению проблем:**
   - Откройте файл `TROUBLESHOOTING.md`
