## 🎯 Как запустить

### 1. Запуск приложения
```bash
# Перейдите в папку с приложением
cd SteamTradeConfirmer/publish

# Запустите приложение
SteamTradeConfirmer.exe
```

### 2. Настройка API ключа
1. **Запустите приложение**
2. **Нажмите кнопку "Настройки"** в левой панели
3. **Вставьте ваш Steam API ключ** в поле
4. **Нажмите "Сохранить"**

### 3. Добавление аккаунта
1. **Нажмите "Добавить"** в левой панели
2. **Введите данные Steam аккаунта:**
   - Имя пользователя
   - Пароль
   - Путь к .maFile
3. **Нажмите "Добавить"**

### 4. Работа с обменами
1. **Дождитесь подключения** аккаунта (статус "Подключен")
2. **Нажмите "Обновить"** для получения списка обменов
3. **Используйте кнопки ✓/✗** для подтверждения/отмены обменов
