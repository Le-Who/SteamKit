## 🔧 Требования

### Обязательные компоненты:
- **Windows 10/11** (64-bit)
- **.NET 8.0 SDK** - [скачать](https://dotnet.microsoft.com/download/dotnet/8.0)
- **Visual Studio 2022** (рекомендуется) или **Visual Studio Code**

### Проверка установки .NET:
```bash
dotnet --version
```
Должно показать версию 8.0.x или выше.

## 🔑 Получение Steam API ключа

1. **Перейдите на страницу Steam Web API:**
   - Откройте браузер и перейдите на https://steamcommunity.com/dev/apikey
   - Войдите в свой аккаунт Steam

2. **Заполните форму:**
   - **Domain Name**: `localhost` (или любой другой домен)
   - **Agree to terms**: поставьте галочку
   - Нажмите **"Register"**

3. **Скопируйте API ключ:**
   - Ключ будет показан на странице (например: `1234567890ABCDEF1234567890ABCDEF`)
   - **Сохраните его в безопасном месте!**

## 🏗️ Сборка проекта

### Способ 1: Через командную строку

1. **Откройте командную строку** в папке проекта:
```bash
cd D:\steaminvapi\SteamKit\SteamTradeConfirmer
```

2. **Восстановите зависимости:**
```bash
dotnet restore
```

3. **Соберите проект:**
```bash
# Debug сборка
dotnet build --configuration Debug

# Release сборка (рекомендуется)
dotnet build --configuration Release
```

4. **Создайте исполняемый файл:**
```bash
# Self-contained (включает .NET Runtime)
dotnet publish --configuration Release --runtime win-x64 --self-contained true --output ./publish

# Framework-dependent (требует установленный .NET)
dotnet publish --configuration Release --runtime win-x64 --self-contained false --output ./publish
```

### Способ 2: Через Visual Studio

1. **Откройте файл решения:**
   - Запустите Visual Studio 2022
   - File → Open → Project/Solution
   - Выберите `SteamTradeConfirmer.sln`

2. **Соберите проект:**
   - Build → Build Solution (Ctrl+Shift+B)
   - Или нажмите F6

3. **Создайте релизную версию:**
   - Build → Publish
   - Выберите папку для публикации
   - Нажмите Publish

## ⚙️ Настройка API ключа

### Способ 1: Через интерфейс приложения

1. **Запустите приложение**
2. **Нажмите кнопку "Настройки"** в левой панели
3. **Вставьте ваш API ключ** в поле "Steam Web API Key"
4. **Нажмите "Сохранить"**

### Способ 2: Прямое редактирование файла

1. **Найдите файл `appsettings.json`** в папке с приложением
2. **Откройте его в текстовом редакторе**
3. **Замените `YOUR_STEAM_API_KEY_HERE`** на ваш реальный API ключ:
```json
{
  "SteamApiKey": "1234567890ABCDEF1234567890ABCDEF",
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "SteamKit2": "Warning"
    }
  }
}
```

## 📱 Получение .maFile

### Вариант 1: Steam Desktop Authenticator

1. **Скачайте SDA:**
   - Перейдите на https://github.com/Jessecar96/SteamDesktopAuthenticator
   - Скачайте последнюю версию

2. **Настройте аутентификатор:**
   - Запустите SDA
   - Добавьте ваш аккаунт Steam
   - Экспортируйте .maFile

### Вариант 2: SteamAuth

1. **Скачайте SteamAuth:**
   - Перейдите на https://github.com/geel9/SteamAuth
   - Скачайте и запустите

2. **Получите .maFile:**
   - Войдите в аккаунт
   - Сохраните файл аутентификатора

### Вариант 3: Ручное извлечение

1. **Найдите папку с аутентификатором:**
   - Обычно в `%APPDATA%/Steam Desktop Authenticator/`
   - Или в папке с SDA

2. **Скопируйте .maFile:**
   - Файл имеет формат: `[steamid].maFile`
   - Скопируйте его в удобное место

## 🔧 Устранение проблем

### Ошибка "SDK not found"
```bash
# Установите .NET 8.0 SDK
# Скачайте с https://dotnet.microsoft.com/download/dotnet/8.0
```

### Ошибка компиляции SteamKit2
```bash
# Соберите SteamKit2 отдельно
cd ../SteamKit2/SteamKit2
dotnet build
```

### Ошибка "API key not configured"
- Проверьте файл `appsettings.json`
- Убедитесь, что API ключ вставлен правильно
- Перезапустите приложение

### Ошибка аутентификации
- Проверьте правильность логина/пароля
- Убедитесь, что .maFile не поврежден
- Проверьте подключение к интернету

### Ошибка "Access denied" при работе с обменами
- Убедитесь, что API ключ действителен
- Проверьте, что аккаунт имеет права на торговлю
- Убедитесь, что обмены действительно существуют

### Приложение не запускается
- Убедитесь, что установлен .NET 8.0 Runtime
- Проверьте антивирус (может блокировать)
- Запустите от имени администратора
